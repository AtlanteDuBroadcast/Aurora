🚀 Exemple d’utilisation (avec curl)
1. Passer en DHCP
curl -X POST http://localhost:5001/set-network \
  -H "Authorization: Bearer supersecrettoken123" \
  -H "Content-Type: application/json" \
  -d '{"interface":"eth0","dhcp":true}'

2. Passer en IP statique
curl -X POST http://localhost:5001/set-network \
  -H "Authorization: Bearer supersecrettoken123" \
  -H "Content-Type: application/json" \
  -d '{"interface":"eth0","dhcp":false,"ip":"192.168.1.200","prefix":"24","gateway":"192.168.1.1","dns":["8.8.8.8","1.1.1.1"]}'

3. Changer hostname
curl -X POST http://localhost:5001/set-hostname \
  -H "Authorization: Bearer supersecrettoken123" \
  -H "Content-Type: application/json" \
  -d '{"hostname":"mon-serveur"}'

4. Configurer NTP
curl -X POST http://localhost:5001/set-ntp \
  -H "Authorization: Bearer supersecrettoken123" \
  -H "Content-Type: application/json" \
  -d '{"servers":["0.pool.ntp.org","1.pool.ntp.org"]}'

5. Reboot
curl -X POST http://localhost:5001/reboot \
  -H "Authorization: Bearer supersecrettoken123"
